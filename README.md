# 角色动作编排引擎

纯 Python 实现，覆盖动作播放、条件状态切换、平滑混合、标记（marker）同步与外部事件；动作资源与角色实例分离，多个角色共用同一批片段时各自保留相位与事件进度。

## 模块

- `animation_engine/clip.py`：不可变关键帧动作与标记、循环边界采样、根移动分段精确积分（支持反向）。
- `animation_engine/player.py`：每个角色独立的播放游标、速度、事件进度、过渡冻结快照与播放状态存取。
- `animation_engine/timing.py`：每角色可变的速度段编排（`SpeedSchedule`），支持落脚放慢/腾空加快与目标步态时长。
- `animation_engine/state_machine.py`：命名状态和基于条件回调的状态切换。
- `animation_engine/library.py`：内置 idle/walk/run（含 `foot_down` 接地脚标记）、`step_dodge` 与带 `windup`/`hit` 事件的 `attack`。

## 标记与事件

标记是共享片段上的只读时间点（`Marker(t, name, payload)`），事件进度（是否已触发）属于每个角色的播放器：

- `request_transition(..., sync_marker="foot_down")` 延续当前接触阶段：计算源片段自最近一次同名标记经过的时间偏移，并按两侧接触周期之比缩放后带入目标片段——异长循环保持*相位*一致（1.2s 周期走到 0.72s 切入 0.6s 周期落在 0.36s；等长周期等同于携带绝对偏移，走路 0.63s 前接地则跑步也从接地后 0.63s 起步），而不是吸附到标记本身造成脚步相位跳变；进入瞬间停在标记上不触发事件。非零标记、循环边界两侧与反向播放时间使用同一套模运算，偏移含义一致。
- 每次切换记录切换前后的接地快照（片段、局部时间、标记后偏移、跨步进度、是否处于接地支撑相），通过 `transition_history()` 回放；快照随 `save_state()` 保存、`load_state()` 恢复。
- 大步推进与逐帧推进使用同一套标记穿越枚举（半开区间 `(t0, t1]`），事件顺序一致、不丢不重；`pop_events()` 取出外部事件（如攻击在 `hit` 标记处造成伤害）。
- 循环片段的标记每一圈至多触发一次（用圈号区分）；非循环片段整个播放期内只触发一次。
- 混合尚未结束时切换第三个动作：当前混合结果被重新冻结后向第三个片段继续 smoothstep，新片段开始新的播放代（generation），切换中途改变播放速度同样只影响后续时间；旧片段尚未到达的标记随片段取消，不会凭空补发，已经进入队列的外部事件保留并照常投递，根位移与脚步事件不重不漏。大步推进、逐帧推进（事件走同一套半开区间穿越枚举）以及在混合中途保存再恢复到新播放器继续，三者的姿态、根部位移与事件顺序一致。
- 保存/恢复包含 generation、已触发表和待投递事件，因此混合中存档后事件序列与未中断播放一致。

## 变速段编排

- `animator.set_speed_schedule([(end, rate), ...], target_duration=...`) 在当前片段上安装每角色独立的速度段：段以片段局部时间的终点划分并覆盖整个周期（循环片段每圈重复），`rate` 为相对速率，例如 `[(0.5, 0.5), (1.0, 2.0)]` 让支撑相前半圈放慢、摆动相后半圈加快；`target_duration` 把整圈步态拉伸到指定的墙钟时长。
- 混合进行中修改速度安排只影响尚未播放的时间：接触标记的到达时刻与脚步事件按新安排触发，已经触发的事件不回写；每圈的根位移由片段本身决定，与匀速播放一致。
- 速度安排随 `save_state()`/`load_state()` 保存恢复；切换到其他片段时安排不随迁（段定义针对具体片段时间轴），带 `sync_marker` 的中途转向仍按相位延续。

## 反向播放与跳转

- `update(dt)` 接受负 `dt`：姿态和根位移精确回退（根积分对有符号时间分段），但反向穿越标记**不触发事件**；恢复正向播放后，已触发过的标记不会重放。
- 混合中反向立即取消混合，按目标片段回退。
- `seek(t)` 是显式跳转：取消进行中的混合、不做姿态平滑，跳过区间内的标记既不补发也不标记为已触发；已触发记录保留，回跳再正向经过不会重放。
- 非循环片段在首尾钳制，不会越过端点播放。

## 连续性设计

过渡不是简单平均两个姿态：新切换会先冻结“当前混合结果”的关节值、根速度和角速度，再向目标片段做 smoothstep 混合。根部位移按混合权重对速度积分，循环边界和关键帧边界自动分段，因此在旧过渡未完成时再次切换不会产生位置跳变。

播放状态包含目标片段、局部时间、播放速度、根部位置/朝向、混合已用时间和冻结快照。保存后用新的播放器载入，再以相同时间步进独立采样，会与未中断播放得到一致结果。
